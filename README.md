# EDT

Emploi du temps M1 AMS (UVSQ), régénéré chaque matin depuis Celcat par le Mac.

- `index.html` — l'interface (vue semaine sur grand écran, vue jour sur téléphone)
- `data.json` — les séances, produites par `edt-refresh`

Publié pour être ajouté à l'écran d'accueil iOS. Aucune donnée personnelle : uniquement l'emploi du temps public du groupe MYAMS1_26.
